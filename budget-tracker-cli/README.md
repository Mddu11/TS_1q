# Budget Tracker CLI

## Описание проекта

Budget Tracker CLI — это консольное приложение для учёта личных финансов.
В дальнейшем приложение можно будет использовать для записи доходов и расходов,
просмотра истории операций и расчёта остатка бюджета.

## Технологии

- TypeScript
- Node.js
- npm

## Установка и запуск

Установить зависимости:

```bash
npm install
```

Скомпилировать TypeScript:

```bash
npm run build
```

Запустить приложение:

```bash
npm start
```
